# 🔥 ARD-016-Arduino-Based-Automatic-Water-Fire-Extinguisher

This project is an automatic fire extinguisher system that uses a **flame sensor**, **two servo motors**, and a **water pump**. One servo motor continuously scans the area with the flame sensor to detect fire and determine its direction. Once fire is detected, the second servo motor rotates the water nozzle toward the fire source, and the water pump is activated to spray water and extinguish the fire automatically.

---

1. [Arduino UNO Original](https://robocraze.com/products/arduino-uno-original)  
2. [SG90 Micro Servo Motor](https://robocraze.com/products/sg90-micro-servo-motor)  
3. [4-Pin KY-026 Flame Sensor Module](https://robocraze.com/products/4pin-ky-026-flame-sensor-module)  
4. [Water Pump](https://robocraze.com/products/water-pump)  
5. [1-Channel 5V Relay Module](https://robocraze.com/products/1-channel-5v-relay-module)
